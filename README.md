# Smart Automatic Height Adjusting Bridge

## Overview
A smart automation project developed using Arduino UNO to simulate an automatic bridge safety and control system during water overflow conditions.

## Project Features
- Automatic bridge uplifting mechanism
- Automatic gate/door closing system
- Water level detection using water sensor
- Emergency alert using buzzer and LED
- Real-time automation using servo motors

## Working Principle
The system continuously monitors water level using a water sensor. When the water level exceeds the defined threshold:

- Red LED glows as a warning signal
- Buzzer starts beeping for alert indication
- Two servo motors automatically close the safety doors on both sides
- Other two servo motors uplift the bridge for safety and water flow management

When water level returns to normal, the bridge and doors return to their default position.
